# 插件场景开发指南

这里按真实项目中的使用场景组织最小教学插件，与 [ch10 插件机制](../guide/ch10-plugins.md) 的四个基础示例配套学习。

::: tip 先看结论，再读原理
每篇指南开头都有「现成方案速览」：先确认这个场景是否已有 Vite 官方能力或成熟社区插件，再决定要不要跟着示例自研。教学代码用于讲清钩子，不等于生产实现。
:::

## 学习方式

每个场景包含插件源码、开发指南和验证步骤：

- **dev 示例**：启动 `pnpm dev`，打开页面头部的「插件」入口，结合 `vite-plugin-inspect`、Network 和控制台观察。
- **构建验证**：构建期插件没有等价的 dev 页面效果，运行指南中的 `pnpm build` 与产物断言。
- **文档服务**：使用 `pnpm docs:dev` 启动本站，按侧边栏分类阅读。

教学插件聚焦核心钩子与数据流。涉及 AST、完整语法解析、安全鉴权、外部服务接入等生产能力时，指南会明确最小实现的边界，不把教学代码误认为可直接上线的通用方案。

每篇开头会标注该场景的现成方案、覆盖程度和自研时机。先选型，再读实现细节。
